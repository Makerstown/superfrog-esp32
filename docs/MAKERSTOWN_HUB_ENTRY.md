# Makerstown HUB — Milestone Superfrog Arcade Edition

**18 ottobre 2026 — Prima release stabile v1.0.0 validata su ESP32-P4**

Superfrog Arcade Edition raggiunge la prima release stabile hardware. Il menu grafico Makerstown, accompagnato dalla traccia "System Boot Sequence", offre due percorsi: **FULL STORY**, con introduzione completa e cambio disco automatico, e **DIRECT GAME**, con avvio autonomo dal Disc 1 e senza attesa dello Story Disc.

Entrambe le modalità sono state testate con successo sul cabinet ESP32-P4. Rimangono congelate le baseline di input GPIO, audio a bassa latenza e presentazione video. Il lampeggio PAL del personaggio resta un difetto grafico noto; in futuro verrà valutata anche una versione ESP32-S3.
